# Node.js Terminal Quiz App

A simple terminal-based quiz application built using Node.js. The quiz tests knowledge on React, Redux, and Node.js with timed questions.

## Features

Loads multiple-choice questions from a JSON file.

Sets a timer for each question and an overall quiz duration.

Tracks user score based on correct answers.

Displays time remaining for each question.

Ends the quiz when all questions are answered or time runs out.

## Technologies Used

Node.js

JavaScript

## Installation

  1. Clone the repository:
  ```
  git clone https://github.com/MandlakheM/nodeJs-quiz-app.git
  ```

  2. Navigate to the project directory:
  ```
  cd nodeJs-quiz-app
  ```

3. Run the quiz:
  ```
  node index.js
  ```

## How to Play

1. The quiz starts automatically when you run the script.

2. Each question is displayed along with multiple-choice options.

3. You have 15 seconds to answer each question.

4. Enter your answer and press Enter.

5. If the answer is correct, your score increases.

6. If time runs out, the quiz moves to the next question.

7. The quiz ends when all questions are answered or the total quiz time (95s) is over.

Enjoy the quiz! 🚀
